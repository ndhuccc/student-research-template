# Student Research Repository

## Repository purpose

This repository stores one student's research code, weekly reports, experiment records, papers, and technical reports.

## Quick start

~~~powershell
python --version
pip install -r requirements.txt
~~~

Replace the commands above with the actual setup commands for this repository.

## Directory guide

- \`weekly-reports/\`: weekly research reports, named \`YYYY-W##.md\`
- \`projects/\`: ordinary subdirectories for research projects; do not create nested Git repositories here
- \`data/\`: data documentation, manifests, checksums, and safe processed data
- \`notebooks/\`: exploratory notebooks
- \`papers/\`: literature notes and paper drafts
- \`reports/\`: technical reports and experiment summaries

## Collaboration rules

1. Keep \`main\` stable.
2. Use a branch for experiments and substantial changes.
3. Add a weekly report for each reporting period.
4. Never commit credentials, personal data, or unapproved raw data.
5. Run \`git status --short --branch\` before and after important work.
