## 4. 實驗方法（必填）

### 4.1 方法摘要

本週要回答的問題是：在資料版本 leaf-v1、固定資料切分與 ResNet-18 架構下，learning rate 由 1e-4、1e-3 或 1e-2 選擇時，哪一個設定能得到較高且穩定的 validation macro-F1。假設是 1e-3 會比 1e-4 收斂較快且維持較佳 F1，而 1e-2 可能因更新步幅過大而不穩定。三組實驗只改變 AdamW 的 learning rate；影像前處理、資料增強、batch size、epoch 數、weight decay、early-stopping 規則、資料切分與模型初始權重均固定。資料來自內部已去識別的葉片影像快照 leaf-v1，共 2,400 張，依病害類別分層，且以植株 ID 避免同一植株的影像出現在不同切分。流程是載入資料、執行相同前處理與增強、以預訓練 ResNet-18 微調 20 epochs，再對 validation split 計算 macro-F1。這是每組僅一個 random seed 的初步比較，因此可用於排除明顯不佳的 1e-2，但不能據此宣稱 1e-3 對 1e-4 有統計上穩定的優勢。

## 4. Experimental Method (Required)

### 4.1 Method Summary

This week’s question was: with data version leaf-v1, a fixed data split, and ResNet-18, which learning rate—1e-4, 1e-3, or 1e-2—yields higher and more stable validation macro-F1? The hypothesis was that 1e-3 would converge faster and retain better F1 than 1e-4, while 1e-2 might be unstable because its update step is too large. The three runs changed only AdamW learning rate; image preprocessing, augmentation, batch size, epoch count, weight decay, early-stopping rule, split, and initial model weights were fixed. The data were an internally de-identified leaf-image snapshot, leaf-v1, with 2,400 images; it was stratified by disease class and grouped by plant ID so images from the same plant could not appear in different splits. The procedure loaded the data, applied the same preprocessing and augmentation, fine-tuned an ImageNet-pretrained ResNet-18 for 20 epochs, and computed macro-F1 on the validation split. This is a preliminary one-seed-per-group comparison, so it can eliminate clearly poor 1e-2 but cannot establish that 1e-3 has a statistically stable advantage over 1e-4.

## 6. Interpretation, Limitations, and Next Technical Decision

- **Supported conclusion:** With seed 42 and fixed v1 split, 1e-3 validation macro-F1 is 0.018 above 1e-4; 1e-2 is substantially worse and appears unstable, so it is not a priority candidate next week.
- **What cannot yet be claimed / needs verification:** We cannot yet claim 1e-3 is better than 1e-4 on the whole dataset or test split, nor infer statistical significance from one seed.
- **Failure/anomaly and plausible cause:** After epoch 6, 1e-2 validation loss rose and F1 varied; a likely cause is an excessive update step, but more seeds are needed to distinguish this from an initialization effect.
- **Next technical decision:** If the five-seed mean macro-F1 of 1e-3 remains at least 0.01 above 1e-4, use 1e-3 as the baseline for augmentation experiments; otherwise retain 1e-4 and prioritize analysis of class imbalance.
